# 管理员使用指南

## 登录管理员账户

| 字段 | 值 |
|------|-----|
| 用户名 | `Admin` |
| 初始密码 | `admin_root` |

> 首次运行程序时自动创建。管理员密码修改后存储在 `users.dat` 中，下次登录使用新密码。

## 管理员菜单

```
=== 管理员系统 ===
当前用户: Admin（管理员）
1、批量添加用户
2、删除用户
3、查看用户列表
4、修改用户密码
5、修改管理员密码
6、系统统计信息
7、数据备份
8、数据恢复
9、初始化系统
10、返回上一级
请选择（输入序号）:
```

### 1. 批量添加用户

一次性添加多个用户：

```
请输入要添加的用户数量: 3

--- 用户 1 ---
请输入用户名: zhangsan
请输入密码: ********
用户 zhangsan 添加成功！

--- 用户 2 ---
请输入用户名: Admin
该用户名是系统保留用户名，跳过！

--- 用户 3 ---
请输入用户名: lisi
请输入密码: ********
用户 lisi 添加成功！

批量添加完成！成功添加 2 个用户。
```

- 自动跳过空用户名、保留用户名（`Admin`）、重复用户名
- 每个用户创建后会生成空的 `用户名.dat` 数据文件

### 2. 删除用户

选择用户并删除：

```
当前用户列表:
1. Admin
2. zhangsan
3. lisi

请输入要删除的用户名（或输入 0 返回）: zhangsan
确认删除用户 zhangsan？(输入 Y 确认，其他键取消): Y
用户删除成功！
```

- 从 `users.dat` 中移除用户记录
- 同时删除该用户的 `用户名.dat` 数据文件
- 删除前需确认

### 3. 查看用户列表

显示所有用户及其平台数量：

```
当前用户列表（共 3 个用户）:
1. Admin   平台数: 0
2. zhangsan   平台数: 5
3. lisi   平台数: 2
```

- 管理员可以看到每个用户保存了多少个平台
- 但**无法查看**用户的具体密码内容

### 4. 修改用户密码

管理员直接重置用户密码（不可查看原密码）：

```
当前用户列表:
1. zhangsan
2. lisi

请输入要修改密码的用户名（或输入 0 返回）: zhangsan
请输入新密码: ********
请确认新密码: ********
用户 zhangsan 的密码修改成功！
```

- 管理员**不能查看**用户的原密码
- 直接设置新密码，需二次确认
- 新密码不能为空

### 5. 修改管理员密码

修改自己的登录密码：

```
请输入当前密码: ********
请输入新密码: ********
密码强度: 强
请确认新密码: ********
管理员密码修改成功！下次登录请使用新密码。
```

- 需验证当前密码
- 输入新密码后会显示密码强度（弱 / 中 / 强 / 非常强）
- 修改后立即生效，存储到 `users.dat`
- 下次登录必须使用新密码

> **注意**：管理员密码修改后存储在加密的 `users.dat` 文件中。`user.cpp` 中的 `getAdminPassword()` 会动态从文件读取，不再依赖编译时常量。

### 6. 系统统计信息

全局数据统计：

```
----------------------------------------
普通用户总数: 3
平台总数:     7
账号总数:     12
----------------------------------------
各用户详情:
1. Admin  -  平台: 0  账号: 0
2. zhangsan  -  平台: 5  账号: 8
3. lisi  -  平台: 2  账号: 4
----------------------------------------
```

- 统计所有用户的平台总数和账号总数
- 显示每个用户的详细平台数和账号数

### 7. 数据备份

将 `data` 目录下的所有文件备份到带时间戳的备份目录：

```
备份完成！
备份目录: backup_2026_08_06_14_30_25
备份文件数: 5
```

- 备份目录命名格式为 `backup_时间戳`（时间戳中的 `:`、空格、`-` 替换为 `_`）
- 备份目录创建在程序同级目录
- 复制 `data/` 目录下的所有文件（`users.dat` 和各用户的 `.dat` 文件）
- 备份文件为加密格式，与原始数据一致

> 建议在进行初始化系统、修改大量用户等操作前先执行数据备份。

### 8. 数据恢复

从备份目录恢复数据，覆盖当前 `data` 目录中的数据：

```
请输入备份目录路径（例如 backup_2026_08_06_12_00_00）: backup_2026_08_06_14_30_25
警告：此操作将覆盖当前所有数据！
确认恢复？(输入 Y 确认，其他键取消): Y
恢复完成！恢复文件数: 5
```

- 需输入备份目录路径（如 `backup_2026_08_06_14_30_25`）
- 恢复前需确认（输入 `Y` 确认，其他键取消）
- 将备份目录中的所有文件复制回 `data/` 目录，**覆盖**当前数据

> **警告**：恢复操作会覆盖 `data/` 目录中的现有数据，建议在恢复前先对当前数据做一次备份。

### 9. 初始化系统

清空所有数据（危险操作）：

```
警告：此操作将删除所有用户数据和密码信息！
确认初始化系统？(输入 Y 确认，其他键取消): Y
系统初始化完成！
```

- 删除所有用户的 `.dat` 数据文件
- 清空 `users.dat` 中的用户列表
- **不可恢复**，请谨慎操作

> 初始化前建议先执行「数据备份」，以便保留可恢复的副本。

### 10. 返回上一级

退出到登录/注册界面。

## 权限说明

| 操作 | 管理员 | 普通用户 |
|------|--------|---------|
| 查看自己密码数据 | 可以（但管理员通常不存密码） | 可以 |
| 查看他人密码数据 | **不可以** | **不可以** |
| 修改他人登录密码 | **可以** | 不可以 |
| 添加/删除用户 | **可以** | 不可以 |
| 查看用户列表 | **可以** | 不可以 |
| 查看系统统计 | **可以** | 不可以 |
| 数据备份 / 恢复 | **可以** | 不可以 |
| 初始化系统 | **可以** | 不可以 |
| 导出自己的密码数据 | 可以（但通常无数据） | **可以** |
| 随机密码生成器 | — | **可以** |
| 注册新用户 | 通过管理员密码授权 | 通过管理员密码授权 |
