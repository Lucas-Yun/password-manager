# 用户使用指南

## 首次使用

1. 运行 `password_manager.exe`
2. 系统自动创建管理员账户
3. 选择「2、注册」，输入管理员密码 `admin_root`
4. 输入用户名和密码完成注册
5. 选择「1、登录」，使用注册的账户登录

## 登录/注册界面

```
=== 密码查询系统 ===
1、登录
2、注册
3、退出
请选择（输入序号）:
```

### 注册流程

1. 输入管理员密码（显示为 `*`）
2. 输入用户名（不能为空、不能与已有用户重名、不能使用保留名 `Admin`）
3. 输入密码（显示为 `*`）
4. 确认密码（两次必须一致）
5. 注册成功后返回主界面重新登录

### 登录流程

1. 输入用户名
2. 输入密码（显示为 `*`）
3. 验证成功后进入对应菜单（管理员或普通用户）

### 1. 添加信息

输入平台名称、多个账号、密码：

```
请输入平台名称: GitHub
请输入账号（输入完成后直接回车，结束输入也直接回车）:
账号1: zhangsan@outlook.com
已添加账号: zhangsan@outlook.com
账号2: zhangsan001
已添加账号: zhangsan001
账号3:                    ← 直接回车结束
请输入密码（或输入 R 自动生成随机密码）: R
已生成随机密码: aB3$efG9kL1mN7pQ
密码强度: 非常强
请输入备注（可选，直接回车跳过）: 主力开发账号
信息添加成功！
```

- 如果平台名已存在，会提示是否覆盖
- 至少需要输入一个账号
- 密码不能为空
- **随机密码**：在输入密码环节输入 `R` 或 `r` 可自动生成 16 位随机密码（含大小写字母、数字、特殊字符）
- **密码强度**：保存前会显示密码强度（弱 / 中 / 强 / 非常强）
- **备注（可选）**：可填写备注信息，直接回车跳过
- **创建时间**：系统自动记录当前时间为创建时间（格式 `YYYY-MM-DD HH:MM:SS`）

### 2. 查询信息

输入平台名称查看密码：

```
请输入平台名称: GitHub
平台 [GitHub] 的信息如下:
账号列表:
  1. zhangsan@outlook.com
  2. zhangsan001
密码: MyP@ssw0rd123
备注: 主力开发账号
创建时间: 2026-08-06 14:30:25
--------------------------------
按 C 复制密码到剪贴板，其他键返回（30秒后自动返回）
```

- 显示备注（若有）和创建时间（若有）
- 按 `C` 键可将密码复制到系统剪贴板
- 密码显示 30 秒后自动返回
- 按其他键可立即返回
- 未找到平台时显示「未查询到信息」

### 3. 删除信息

显示平台列表后选择删除：

```
当前已保存的平台列表:
1. GitHub
2. Gmail
3. Steam

请输入要删除的平台名称（或输入 0 返回）: Steam
确认删除平台 [Steam] 的所有信息？(输入 Y 确认，其他键取消): Y
删除成功！
```

- 输入 `0` 可取消返回
- 删除前需确认，防止误删

### 4. 平台列表

总览所有已保存的平台：

```
共保存了 3 个平台:
----------------------------------------
1. [GitHub]   账号数: 2   创建: 2026-08-06 14:30:25
2. [Gmail]   账号数: 1   创建: 2026-08-05 09:12:03
3. [Steam]   账号数: 3   创建: 2026-08-04 18:45:50
----------------------------------------
账号总数: 6 个
```

- 每个平台显示账号数和创建时间（若有）

### 5. 编辑信息

选择平台后进入编辑子菜单：

```
=== 编辑平台 [GitHub] ===
当前账号:
  1. zhangsan@outlook.com
  2. zhangsan001
当前密码: ********
当前备注: 主力开发账号
创建时间: 2026-08-06 14:30:25
--------------------------------
1、添加账号
2、删除账号
3、修改密码
4、重命名平台
5、编辑备注
6、保存并返回
请选择:
```

- **添加账号**：输入新账号直接回车确认
- **删除账号**：输入序号删除指定账号
- **修改密码**：输入新密码（支持输入 `R` 自动生成随机密码）并二次确认，保存前显示密码强度
- **重命名平台**：输入新名称（不能与已有平台重名）
- **编辑备注**：输入新备注，直接回车可清除备注
- **保存并返回**：至少保留一个账号才能保存

### 6. 搜索平台

模糊搜索平台名和账号名：

```
请输入搜索关键词（支持模糊搜索）: git
找到 1 个匹配结果:
----------------------------------------
1. [GitHub]
   账号: zhangsan@outlook.com, zhangsan001
----------------------------------------
输入序号查看详细信息（0 返回）: 1

=== 详细信息 ===
平台: GitHub
账号列表:
  1. zhangsan@outlook.com
  2. zhangsan001
密码: MyP@ssw0rd123
备注: 主力开发账号
创建时间: 2026-08-06 14:30:25
--------------------------------
按 C 复制密码到剪贴板，其他键返回（30秒后自动返回）
```

- 搜索不区分大小写
- 同时匹配平台名和账号名
- 详情显示备注（若有）和创建时间（若有）
- 详情页按 `C` 键可将密码复制到剪贴板
- 查看详情同样有 30 秒自动返回机制

### 7. 修改密码

修改自己的登录密码：

```
请输入当前密码: ********
请输入新密码: ********
密码强度: 强
请确认新密码: ********
密码修改成功！
```

- 需验证当前密码
- 新密码不能为空
- 输入新密码后会显示密码强度（弱 / 中 / 强 / 非常强）
- 两次新密码必须一致
- 新密码不能与原密码相同

### 8. 导出数据

将当前用户的所有平台信息导出为明文文本文件：

```
请输入导出文件路径（直接回车使用默认 export_<用户名>.txt）:
（直接回车）
数据已导出到: export_zhangsan.txt
警告: 导出文件为明文，请注意安全！
```

- 默认导出文件名为 `export_用户名.txt`
- 可自定义导出文件路径
- 导出内容包括：用户名、导出时间、平台总数，以及每个平台的账号列表、密码、备注（若有）、创建时间（若有）

> **警告**：导出文件为**明文**，包含所有密码，请妥善保管，使用后及时删除。

导出文件示例：

```
========== 密码导出 ==========
用户: zhangsan
导出时间: 2026-08-06 14:30:25
平台总数: 3
==============================

【平台】GitHub
  账号列表:
    1. zhangsan@outlook.com
    2. zhangsan001
  密码: MyP@ssw0rd123
  备注: 主力开发账号
  创建时间: 2026-08-06 14:30:25
```

### 9. 随机密码生成器

生成指定长度的随机密码，可复制或重新生成：

```
请输入密码长度（8-64，默认16）: 20

生成的密码: xK9$mP2#nL7&qR4vT8wZ
密码长度: 20
密码强度: 非常强
--------------------------------
按 C 复制到剪贴板，R 重新生成，其他键返回:
```

- 长度范围 8-64 位，默认 16 位
- 字符集包含：大写字母、小写字母、数字、特殊字符（`!@#$%^&*_-+=`）
- 保证至少包含每种字符各一个
- 按 `C` 键复制到剪贴板
- 按 `R` 键重新生成密码
- 按其他键返回

### 10. 返回上一级

退出到登录/注册界面。
