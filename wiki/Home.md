# PasswordManager Wiki

欢迎来到 PasswordManager 密码查询系统 Wiki！

## 项目简介

PasswordManager 是一个基于 C++ 开发的本地密码管理系统，支持多用户隔离、加密存储、管理员后台等功能。所有数据加密后存储在本地文件中，无需网络连接。

## 核心特性

- **多用户隔离**：每个用户的数据独立存储，A 用户无法访问 B 用户的数据
- **XTEA-CBC 加密**：128 位密钥 + CBC 模式 + PKCS7 填充，每次加密使用随机 IV
- **管理员后台**：批量用户管理、系统统计、初始化等功能
- **密码隐藏输入**：所有密码输入显示为 `*`，支持退格删除
- **自动格式升级**：读取旧版 XOR 数据时自动升级为新版 XTEA-CBC 格式
- **数据转换工具**：独立的转换程序，带备份和回读验证
- **随机密码生成**：可生成 8-64 位随机密码（含大小写字母、数字、特殊字符）
- **密码强度检测**：实时检测密码强度（弱 / 中 / 强 / 非常强）
- **剪贴板复制**：查询 / 搜索时按 C 键一键复制密码到剪贴板
- **数据备份与恢复**：管理员可一键备份 `data` 目录，从备份目录恢复数据
- **数据导出**：将所有平台信息导出为明文文本文件

## 功能总览

### 普通用户（10 项功能）

1. 添加信息（平台名 + 多账号 + 密码，支持输入 R 生成随机密码、显示密码强度、可输入备注、自动记录创建时间）
2. 查询信息（显示备注和创建时间，按 C 键复制密码到剪贴板，30 秒自动返回）
3. 删除信息（带平台列表选择 + 确认）
4. 平台列表（总览所有平台和账号统计，显示创建时间）
5. 编辑信息（增删账号 / 改密码 / 重命名平台 / 编辑备注，改密码支持随机生成和强度检测）
6. 搜索平台（模糊搜索平台名和账号名，详情显示备注和创建时间，按 C 键复制密码到剪贴板）
7. 修改密码（验证当前密码 + 二次确认，显示密码强度）
8. 导出数据（导出所有平台信息为明文文本文件）
9. 随机密码生成器（可指定长度 8-64 位，支持复制到剪贴板、重新生成）
10. 返回上一级

### 管理员（10 项功能）

1. 批量添加用户
2. 删除用户（同时删除用户数据文件）
3. 查看用户列表（含每人平台数量）
4. 修改用户密码（不可查看原密码）
5. 修改管理员密码（立即生效，显示密码强度）
6. 系统统计信息（总用户数 / 平台数 / 账号数）
7. 数据备份（将 data 目录所有文件备份到 backup_时间戳 目录）
8. 数据恢复（从备份目录恢复数据，覆盖当前数据，带确认）
9. 初始化系统（清空所有数据）
10. 返回上一级

## 默认管理员账户

| 字段 | 值 |
|------|-----|
| 用户名 | `Admin` |
| 初始密码 | `admin_root` |

> 首次运行程序时自动创建管理员账户。建议登录后立即修改密码。
