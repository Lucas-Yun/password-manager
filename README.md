# PasswordManager · 本地密码查询系统

**一个跑在自己电脑里的命令行密码本。** 密码用 XTEA-CBC 加密后存在本地文件里，多用户数据互不可见，管理员能看到谁在用，但看不到任何人的明文密码。

纯 C++ 实现 · Windows 控制台程序 · 无网络请求 · 数据只存在自己的 `data/` 目录

## 这是什么

把「一堆网站的账号密码」存进一个本地加密文件，用自己的登录密码打开，按平台名查出来、复制到剪贴板。全程不联网，不上云，不依赖浏览器或密码管理服务。

**适合：**

- 想自己掌控密码数据、不信任云同步的人；
- 学习加密实现（XTEA-CBC 的完整落地示例，含 IV 与 PKCS7 填充）；
- 需要离线环境（教室机房、内网、没有网络的旧机器）。

**不适合：** 需要浏览器自动填充、手机同步、跨设备云备份的场景——那是 Bitwarden / KeePassXC 的领域。本项目刻意只做本地单机。

## 三分钟跑起来

```bash
make run
```

没有 Makefile 环境时，等价于：

```bash
g++ -std=c++11 -Wall -Iinclude src/main.cpp src/crypto.cpp src/file_io.cpp src/user.cpp src/menu.cpp -o password_manager.exe
password_manager.exe
```

首次运行会自动创建 `data/` 目录和管理员账户：

1. 选择「2、注册」，管理员密码填 `admin_root`；
2. 输入自己的用户名和密码完成注册；
3. 之后用「1、登录」进入，开始添加平台和账号。

> 第一次登录后请立刻在菜单里改掉管理员密码（改完立即生效，不用重新编译）。

## 它解决什么问题

| 你遇到的 | 这个程序的回答 |
| --- | --- |
| 一堆密码记在 txt 里，谁打开都能看 | 全部密文存储，`users.dat` 和 `<用户名>.dat` 都是 XTEA-CBC 加密后的二进制 |
| 同一个网站注册了好几个账号，记不清 | 每个平台下可挂多个账号，支持子菜单增删、重命名、改密码、写备注 |
| 密码太简单，自己都心虚 | 内置密码强度检测（弱/中/强/非常强）和一键随机强密码生成（8–64 位） |
| 手动抄密码容易错 | 查询时按 `C` 直接复制到剪贴板，30 秒后自动返回，不留在屏幕上 |
| 换个电脑就丢数据 | 管理员可一键备份整个 `data/` 到带时间戳的目录，也能从备份恢复 |
| 多人共用一台机器 | 每个用户数据完全隔离，A 用户读不到 B 用户的数据文件；管理员能重置密码，但**看不到**原密码 |

## 安全设计

这是本项目最值得看的部分，实现细节在 [`wiki/Encryption.md`](wiki/Encryption.md)。

| 项目 | 说明 |
| --- | --- |
| 算法 | XTEA（eXtended Tiny Encryption Algorithm），32 轮 |
| 密钥长度 | 128 位（4 × 32 位） |
| 工作模式 | CBC（密码块链接） |
| 填充方式 | PKCS7 |
| IV | 每次加密随机生成 8 字节，**同一份明文两次加密结果不同** |
| 文件格式 | `[版本标识 0x02]` + `[IV 8 字节]` + `[密文]` |
| 其他 | 密码输入全 `*` 掩码；注册需管理员密码；改密需验证旧密码 + 二次确认；用户数据文件隔离 |

**边界说清楚**：这是「本地防窥」级别的方案，不是抗专业密码分析的产品。密钥在程序内，能拿到 exe 和内存的人可以还原算法；真要对抗物理接触攻击，请用 KeePassXC / Bitwarden 这类经过审计的方案。本项目对标的场景是「不要让同桌随手打开 txt 就看到我的密码」。

## 功能清单

### 普通用户（10 项功能）

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 添加信息 | 输入平台名称、多个账号、密码；支持随机密码生成、密码强度检测、备注、自动记录创建时间 |
| 2 | 查询信息 | 显示账号、密码、备注和创建时间；支持按 C 键复制密码到剪贴板，30 秒自动返回 |
| 3 | 删除信息 | 显示平台列表后选择删除，带确认步骤，防误删 |
| 4 | 平台列表 | 浏览所有已保存的平台，显示账号数量、创建时间和总数统计 |
| 5 | 编辑信息 | 子菜单：添加/删除账号、修改密码（含强度检测和随机生成）、重命名平台、编辑备注 |
| 6 | 搜索平台 | 模糊搜索平台名和账号名，查看详情时支持复制密码到剪贴板 |
| 7 | 修改密码 | 验证当前密码后修改登录密码，显示密码强度 |
| 8 | 导出数据 | 将所有平台信息导出为明文文本文件（含备注和创建时间） |
| 9 | 随机密码生成器 | 可指定长度（8–64 位），支持复制到剪贴板、重新生成 |
| 10 | 返回上一级 | 退出到登录/注册界面 |

### 管理员（10 项功能）

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 批量添加用户 | 一次性添加多个用户，自动跳过重复/空用户名 |
| 2 | 删除用户 | 显示用户列表，选择删除，同时删除该用户的所有数据文件 |
| 3 | 查看用户列表 | 显示所有普通用户及每人保存的平台数量 |
| 4 | 修改用户密码 | 管理员直接重置普通用户密码（不可查看原密码） |
| 5 | 修改管理员密码 | 验证当前密码后修改自己的登录密码（立即生效），显示密码强度 |
| 6 | 系统统计信息 | 总用户数、总平台数、总账号数及各用户详情统计 |
| 7 | 数据备份 | 将 data 目录下所有数据文件备份到带时间戳的目录 |
| 8 | 数据恢复 | 从备份目录恢复数据（覆盖当前数据，带确认） |
| 9 | 初始化系统 | 清空所有用户及密码数据（带警告确认） |
| 10 | 返回上一级 | 退出到登录/注册界面 |

### 安全特性

- 密码输入隐藏显示（`*`）
- XTEA 块加密算法 + CBC 模式 + PKCS7 填充（128 位密钥，32 轮加密）
- 每次加密使用随机 IV，相同数据每次加密结果不同
- 仅保留 XTEA-CBC 一种加密方案
- 用户数据完全隔离（A 用户无法访问 B 用户数据）
- 管理员不可查看普通用户的密码隐私
- 注册需管理员密码验证，防止恶意注册
- 修改密码需验证当前密码 + 二次确认新密码
- 密码强度检测：添加/修改密码时显示强度等级（弱/中/强/非常强）
- 随机密码生成：支持生成包含大小写字母、数字、特殊字符的强密码
- 剪贴板复制：查询密码时可直接复制到剪贴板，避免手动输入
- 数据备份与恢复：管理员可随时备份和恢复系统数据

## 环境要求

- **操作系统**：Windows（用了 `windows.h`、`conio.h`，Linux/macOS 需自行替换控制台相关调用）
- **编译器**：MinGW g++，支持 C++11
- **依赖库**：仅 Windows API，无第三方库

## 编译与运行

### 使用 Makefile

```bash
make          # 编译主程序 + 诊断测试
make main     # 仅编译主程序
make test     # 仅编译诊断测试
make run      # 编译并运行主程序
make clean    # 清理编译产物
```

### 手动编译

```bash
# 主程序
g++ -std=c++11 -Wall -finput-charset=UTF-8 -Iinclude ^
    src/main.cpp src/crypto.cpp src/file_io.cpp src/user.cpp src/menu.cpp ^
    -o password_manager.exe
```

### 运行

```bash
password_manager.exe    # 主程序
```

## 使用说明

### 首次使用

1. 运行程序，系统自动创建管理员账户；
2. 选择「2、注册」，输入管理员密码 `admin_root`；
3. 输入用户名和密码完成注册；
4. 选择「1、登录」使用注册的账户登录。

### 管理员登录

- **用户名**：`Admin`
- **初始密码**：`admin_root`
- 登录后可在菜单中修改管理员密码（修改后立即生效，无需重新编译）。

## 模块说明

| 模块 | 文件 | 职责 |
|------|------|------|
| 加密模块 | `crypto.h/cpp` | XTEA-CBC 加密解密、PKCS7 填充、密码隐藏输入、随机密码生成、密码强度检测、剪贴板操作 |

## 已知限制

- 仅 Windows；Linux/macOS 需要替换控制台 API；
- 单一加密方案，密钥硬编码在程序中，属于本地防窥档位，不抗专业密码分析；
- 「导出数据」输出明文，导出后请自行保管或删除；
- 没有浏览器自动填充和移动端支持——这是设计取舍，不是缺失功能。
