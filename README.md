# PasswordManager 密码查询系统

基于 C++ 开发的本地密码管理系统，支持用户注册/登录、密码加密存储、多账号管理、管理员后台等功能。

## 功能特性

### 普通用户（8 项功能）

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 添加信息 | 输入平台名称、多个账号（支持多账号）、密码；重复平台名可选择覆盖 |
| 2 | 查询信息 | 输入精确平台名称，显示账号和密码，30秒后自动返回或按任意键返回 |
| 3 | 删除信息 | 显示平台列表后选择删除，带确认步骤，防误删 |
| 4 | 平台列表 | 浏览所有已保存的平台，显示账号数量和总数统计 |
| 5 | 编辑信息 | 子菜单功能：添加/删除账号、修改密码、重命名平台 |
| 6 | 搜索平台 | 模糊搜索平台名和账号名，输入序号可查看详细信息（30秒显示） |
| 7 | 修改密码 | 验证当前密码后，修改自己的登录密码 |
| 8 | 返回上一级 | 退出到登录/注册界面 |

### 管理员（8 项功能）

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 批量添加用户 | 一次性添加多个用户，自动跳过重复/空用户名 |
| 2 | 删除用户 | 显示用户列表，选择删除，同时删除该用户的所有数据文件 |
| 3 | 查看用户列表 | 显示所有普通用户及每人保存的平台数量 |
| 4 | 修改用户密码 | 管理员直接重置普通用户密码（不可查看原密码） |
| 5 | 修改管理员密码 | 验证当前密码后修改自己的登录密码（立即生效） |
| 6 | 系统统计信息 | 总用户数、总平台数、总账号数及各用户详情统计 |
| 7 | 初始化系统 | 清空所有用户及密码数据（带警告确认） |
| 8 | 返回上一级 | 退出到登录/注册界面 |

### 安全特性

- 密码输入隐藏显示（`*`）
- **XTEA 块加密算法 + CBC 模式 + PKCS7 填充**（128位密钥，32轮加密）
- 每次加密使用随机 IV（初始化向量），相同数据每次加密结果不同
- 仅保留 XTEA-CBC 一种加密方案
- 用户数据完全隔离（A 用户无法访问 B 用户数据）
- 管理员不可查看普通用户的密码隐私
- 注册需管理员密码验证，防止恶意注册
- 修改密码需验证当前密码 + 二次确认新密码

## 环境要求

- **操作系统**: Windows
- **编译器**: MinGW g++ (支持 C++11)
- **依赖库**: Windows API (`windows.h`, `conio.h`)

## 编译与运行

### 使用 Makefile

```bash
make          # 编译主程序 + 诊断测试
make main     # 仅编译主程序
make test     # 仅编译诊断测试
make run      # 编译并运行主程序
make clean    # 清理编译产物
```

### 手动编译

```bash
# 主程序
g++ -std=c++11 -Wall -finput-charset=UTF-8 -Iinclude ^
    src/main.cpp src/crypto.cpp src/file_io.cpp src/user.cpp src/menu.cpp ^
    -o password_manager.exe
```

### 运行

```bash
password_manager.exe    # 主程序
```

## 加密方案

### XTEA-CBC

| 项目 | 说明 |
|------|------|
| 算法 | XTEA (eXtended Tiny Encryption Algorithm) |
| 密钥长度 | 128 位（4 x 32位） |
| 加密轮数 | 32 轮 |
| 工作模式 | CBC（密码块链接） |
| 填充方式 | PKCS7 |
| IV（初始化向量）| 8 字节随机生成 |
| 文件格式 | `[版本标识 0x02]` + `[IV 8字节]` + `[密文]` |

## 使用说明

### 首次使用

1. 运行程序，系统自动创建管理员账户
2. 选择「2、注册」，输入管理员密码 `admin_root`
3. 输入用户名和密码完成注册
4. 选择「1、登录」使用注册的账户登录

### 管理员登录

- **用户名**: `Admin`
- **初始密码**: `admin_root`
- 登录后可在菜单中修改管理员密码（修改后立即生效，无需重新编译）

### 数据存储

- 用户数据: `data/users.dat`（XTEA 加密存储）
- 用户密码: `data/<用户名>.dat`（XTEA 加密存储）
- 数据目录在程序首次运行时自动创建

## 模块说明

| 模块 | 文件 | 职责 |
|------|------|------|
| 加密模块 | `crypto.h/cpp` | XTEA-CBC 加密解密、PKCS7 填充、密码隐藏输入 |
| 文件模块 | `file_io.h/cpp` | 用户数据与密码数据的加载/保存 |
| 用户模块 | `user.h/cpp` | 用户注册、登录验证、管理员密码动态读取 |
| 菜单模块 | `menu.h/cpp` | 界面展示、业务逻辑、输入处理、搜索/编辑/统计功能 |
| 类型定义 | `types.h` | 全局常量、加密密钥与数据结构 |
| 诊断测试 | `crypto_test.cpp` | XTEA-CBC 加解密一致性验证 |
